# Calculadora 3D — downloads

Instalador para Windows da **Calculadora 3D** (custo de impressão 3D, orçamento no WhatsApp e envio para a impressora).

- Baixe o arquivo `Calculadora3D-Setup-<versão>.exe` na página **[Releases](../../releases/latest)**.
- O app se atualiza sozinho: quando sair uma versão nova, ele baixa em segundo plano e avisa para reiniciar.

Este repositório contém apenas os instaladores (sem código-fonte).
